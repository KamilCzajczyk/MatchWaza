# MatchWaza (マッチ技)

> A simple, intuitive memory matching game designed to teach Japanese vocabulary through Polish translations.

**MatchWaza** combines classic card-matching mechanics with language learning. Players flip cards to pair Japanese terms with their Polish equivalents, leveraging visual and spatial memory to reinforce vocabulary retention.

---

## 🚀 Features

- 🎌 **Japanese-Polish Pairings:** Practice Kanji, Kana, and Romaji paired directly with Polish translations.
- 🎴 **Interactive Card Flipping:** Responsive CSS 3D card-flip animations and tactile visual feedback.
- ⏱️ **Game Statistics:** Real-time tracking of timer, total moves, and accuracy rating.
- 📚 **Customizable Decks:** Easily edit, expand, or swap word decks via structured JSON files.
- 📱 **Responsive Design:** Optimized for both desktop displays and mobile touchscreens.
